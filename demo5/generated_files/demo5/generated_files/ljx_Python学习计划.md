# 🐍 Python 学习计划 — ljx

> 本计划面向零基础或有一定编程基础的学习者，周期为 **12 周**，目标为掌握 Python 核心语法、常用库及项目实战能力。

---

## 📅 第一阶段：基础入门（第 1-3 周）

### 第 1 周：Python 环境搭建与基础语法
- [ ] 安装 Python（推荐 3.10+）与 IDE（VS Code / PyCharm）
- [ ] 第一个程序：`print("Hello, World!")`
- [ ] 变量与数据类型（int, float, str, bool）
- [ ] 输入输出：`input()` 与 `print()`
- [ ] 注释与代码规范

### 第 2 周：流程控制
- [ ] 条件判断：`if`、`elif`、`else`
- [ ] 循环：`for` 循环与 `while` 循环
- [ ] `break`、`continue`、`pass`
- [ ] 列表推导式基础

### 第 3 周：数据结构
- [ ] 列表（list）与元组（tuple）
- [ ] 字典（dict）与集合（set）
- [ ] 字符串常用方法
- [ ] 切片操作

---

## 📅 第二阶段：进阶核心（第 4-7 周）

### 第 4 周：函数与模块
- [ ] 函数定义与调用
- [ ] 参数类型（位置参数、默认参数、关键字参数、可变参数）
- [ ] 返回值与 `return`
- [ ] 匿名函数 `lambda`
- [ ] 模块导入与 `__name__` 属性

### 第 5 周：文件操作与异常处理
- [ ] 文件读写：`open()`、`with` 语句
- [ ] 异常处理：`try`、`except`、`finally`
- [ ] 自定义异常

### 第 6 周：面向对象编程（OOP）
- [ ] 类与对象
- [ ] 构造函数 `__init__`
- [ ] 继承与多态
- [ ] 封装与属性装饰器 `@property`

### 第 7 周：常用标准库
- [ ] `os`、`sys`、`datetime`
- [ ] `json`、`re`（正则表达式）
- [ ] `math`、`random`
- [ ] `collections` 模块

---

## 📅 第三阶段：实用工具与库（第 8-10 周）

### 第 8 周：第三方库入门
- [ ] pip 包管理工具
- [ ] 虚拟环境（venv）
- [ ] 安装与使用常用库：`requests`、`beautifulsoup4`

### 第 9 周：数据处理基础
- [ ] NumPy 基础
- [ ] Pandas 基础（Series、DataFrame）
- [ ] 数据可视化：Matplotlib 基础绘图

### 第 10 周：Web 开发入门
- [ ] Flask 框架基础
- [ ] 路由与模板渲染
- [ ] 简单的 REST API

---

## 📅 第四阶段：项目实战（第 11-12 周）

### 第 11 周：小项目练习
- [ ] 命令行待办事项管理器
- [ ] 爬虫抓取网页数据
- [ ] 数据分析小报告

### 第 12 周：综合项目
- [ ] 选题：个人博客 / 数据分析仪表盘 / 自动化脚本
- [ ] 项目规划与代码结构
- [ ] 测试与调试
- [ ] 部署上线（可选）

---

## 📌 学习建议

- 每天坚持 **30 分钟 ~ 1 小时** 编码练习
- 善用官方文档：[docs.python.org](https://docs.python.org/)
- 遇到问题先自己搜索（Stack Overflow、Google）
- 多写代码、多记笔记、多做项目
