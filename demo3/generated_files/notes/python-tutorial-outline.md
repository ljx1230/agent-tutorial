# Python 教程大纲

## 一、Python 基础入门
- Python 简介与环境搭建
- 基本语法与变量
- 数据类型（数字、字符串、布尔值）
- 输入与输出
- 注释与代码规范

## 二、流程控制
- 条件判断（if / elif / else）
- 循环结构（for、while）
- break 与 continue
- 列表推导式

## 三、数据结构
- 列表（list）
- 元组（tuple）
- 字典（dict）
- 集合（set）
- 字符串操作

## 四、函数
- 函数定义与调用
- 参数传递（位置参数、默认参数、关键字参数、可变参数）
- 返回值
- 匿名函数（lambda）
- 作用域与闭包
- 装饰器

## 五、模块与包
- 模块导入（import）
- 标准库常用模块（os、sys、math、random、datetime）
- 自定义模块与包
- pip 包管理工具

## 六、文件操作
- 文件读写（open、with）
- 文件路径处理（os.path / pathlib）
- CSV 与 JSON 文件处理

## 七、面向对象编程（OOP）
- 类与对象
- 继承与多态
- 封装与属性
- 特殊方法（\_\_init\_\_、\_\_str\_\_ 等）
- 类方法与静态方法

## 八、异常处理
- try / except / finally
- 自定义异常
- 断言（assert）

## 九、进阶主题
- 迭代器与生成器
- 上下文管理器
- 多线程与多进程
- 异步编程（asyncio）
- 正则表达式

## 十、实用工具与库
- 虚拟环境（venv）
- 单元测试（unittest / pytest）
- 日志记录（logging）
- 常用第三方库简介（requests、numpy、pandas、matplotlib）

## 十一、项目实战
- 命令行工具开发
- 爬虫入门
- Web 开发入门（Flask / FastAPI）
- 数据分析小项目

---

> 本大纲适用于 Python 初学者到进阶学习者，可根据实际需求调整学习顺序和深度。
