# Python 学习计划

## 第一阶段：基础入门（第 1-2 周）

### 第 1 周：Python 环境与基础语法
- [ ] 安装 Python 和 IDE（推荐 VS Code 或 PyCharm）
- [ ] 学习基本数据类型：整数、浮点数、字符串、布尔值
- [ ] 掌握变量与赋值
- [ ] 学习输入输出：`print()` 和 `input()`
- [ ] 了解注释的写法

### 第 2 周：流程控制
- [ ] 条件语句：`if`、`elif`、`else`
- [ ] 循环语句：`for` 循环和 `while` 循环
- [ ] `break` 和 `continue` 的使用
- [ ] 列表、元组、字典的基本操作

## 第二阶段：进阶核心（第 3-4 周）

### 第 3 周：函数与模块
- [ ] 定义和调用函数
- [ ] 参数传递：位置参数、默认参数、关键字参数
- [ ] 返回值与作用域
- [ ] 导入和使用标准库模块

### 第 4 周：文件操作与异常处理
- [ ] 文件的读写操作（`open`、`read`、`write`）
- [ ] `with` 语句的使用
- [ ] 异常捕获：`try`、`except`、`finally`
- [ ] 自定义异常

## 第三阶段：面向对象与实用工具（第 5-6 周）

### 第 5 周：面向对象编程
- [ ] 类与对象的定义
- [ ] 属性和方法
- [ ] 继承与多态
- [ ] 特殊方法（`__init__`、`__str__` 等）

### 第 6 周：常用库与工具
- [ ] `datetime` 和 `math` 库
- [ ] `os` 和 `sys` 模块
- [ ] 第三方库安装（`pip` 的使用）
- [ ] 简单项目练习：计算器或待办事项应用

## 第四阶段：实战项目（第 7-8 周）

### 第 7 周：Web 开发入门
- [ ] 了解 Flask 或 FastAPI 框架
- [ ] 搭建简单的 Web 应用
- [ ] 路由与模板渲染

### 第 8 周：综合项目
- [ ] 选题：个人博客、数据分析脚本或爬虫
- [ ] 项目规划与代码实现
- [ ] 代码调试与优化
- [ ] 总结与复盘

---

> **建议**：每天坚持编码至少 30 分钟，遇到问题多查官方文档和 Stack Overflow。
